# Nonlinear-causality-of-Israel-Stewart-theory-with-diffusion
Calculations for "Nonlinear causality of Israel-Stewart theory with diffusion". Preprint: https://arxiv.org/abs/2507.20064

Mathematica notebook contains (1) calculation of the characteristic determinant in both Eckart and Landau hydrodynamic frames by shifting into the fluid local rest frame, (2) all relevant nonlinear causality bounds for each case and (3) the numerical calculation of the maximum attainable heat diffusion allowed by nonlinear causality for the ultrarelativistic ideal gas in D = 1 + 1.
